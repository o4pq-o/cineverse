# Cinevers

موقع ويب جامعي بسيط لعرض الأفلام والمسلسلات. يركز Cinevers على تقديم واجهة عربية واضحة وسهلة الاستخدام لعرض الأعمال، البحث عنها، والانتقال إلى صفحة تفاصيل كل عمل.

## التقنيات المستخدمة

- HTML5
- CSS3
- Vanilla JavaScript

لا يستخدم المشروع أي إطار عمل أو مكتبة أو Backend أو قاعدة بيانات.

## المزايا

- خمس صفحات: الرئيسية، الاستكشاف، التفاصيل، تسجيل الدخول، وإنشاء حساب.
- شريط تنقل وتذييل موحّدان في الصفحات.
- سلايدر تلقائي في الصفحة الرئيسية باستخدام JavaScript.
- بطاقات للأفلام والمسلسلات تعرض الملصق والاسم والتقييم والوصف المختصر.
- بحث فوري باسم الفيلم أو المسلسل.
- صفحة تفاصيل تقرأ رقم العمل من الرابط.
- تصميم متجاوب للجوال والشاشات الكبيرة.
- صور وملفات خط محلية ليعمل المشروع دون اتصال بالإنترنت.

## تشغيل المشروع

1. حمّل المشروع وفك ضغطه إن كان بصيغة ZIP.
2. افتح مجلد `cineverse` في VS Code.
3. افتح ملف `index.html` مباشرة في المتصفح، أو استخدم إضافة Live Server في VS Code.

لا يحتاج المشروع إلى تثبيت حزم أو تشغيل أوامر.

## هيكل المشروع

```text
cineverse/
├── assets/
│   ├── fonts/       # الخط المحلي
│   └── images/      # ملصقات الأعمال
├── css/
│   └── style.css
├── js/
│   └── script.js
├── index.html
├── browse.html
├── details.html
├── login.html
└── signup.html
```

## ملاحظات للمناقشة

- بيانات الأعمال موجودة داخل المصفوفة `items` في `js/script.js` لتبسيط المشروع وعدم الحاجة إلى قاعدة بيانات.
- البحث يعرض العناصر التي يحتوي اسمها على النص المكتوب في حقل البحث.
- صفحة التفاصيل تستخدم `URLSearchParams` لقراءة `id` من رابط الصفحة.
